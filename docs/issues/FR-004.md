# [FR-004] Sentence-Level Waveform Inspector & Synchronized Playback

## Labels
`MUS`, `enhancement`, `waveform-editor`, `ui-ux`

## User Story
As an audio editor, I want to see an interactive waveform for each synthesized sentence with teleprompter-style sentence highlighting as audio plays so that I can immediately detect audio defects or mispronunciations.

## Proposed Solution

### Overview
Integrate `wavesurfer.js` v7 into the bottom studio panel. When a sentence is selected or played, its audio waveform is rendered with high-precision time ruler, zoom slider, and playback controls. While playing through multiple sentences in sequence, the text editor highlights the active sentence (Karaoke/Teleprompter sync).

### Implementation Flow
1. Load sentence audio via Tauri custom protocol `asset://` or base64 stream.
2. Initialize `WaveSurfer` container in `WaveformPanel.tsx` with:
   - Wave color: primary brand violet/indigo (`#6366f1`).
   - Progress color: highlight violet (`#a855f7`).
   - Plugins: `Timeline` (seconds ruler) and `Hover` (cursor preview).
3. Connect audio playback events:
   - `timeupdate`: update current timestamp indicator.
   - `finish`: automatically advance to the next sentence if "Continuous Play" is enabled.
4. Teleprompter sync: Auto-scroll sentence table to keep the active reading sentence centered on screen.

### Technical Approach

```typescript
import WaveSurfer from 'wavesurfer.js';
import TimelinePlugin from 'wavesurfer.js/dist/plugins/timeline.esm.js';

const ws = WaveSurfer.create({
  container: containerRef.current,
  waveColor: '#4f46e5',
  progressColor: '#9333ea',
  cursorColor: '#f43f5e',
  barWidth: 2,
  barGap: 1,
  barRadius: 2,
  plugins: [TimelinePlugin.create()],
});
```
