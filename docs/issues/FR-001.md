# [FR-001] Ebook Ingestion & Metadata Extraction

## Labels
`MUS`, `enhancement`, `ebook-parser`, `tauri-backend`

## User Story
As an audiobook creator, I want to drag & drop EPUB, PDF, or MOBI files into the application so that it automatically parses the title, author, cover image, and full chapter structure (TOC).

## Proposed Solution

### Overview
Implement native Rust ebook parsers in `src-tauri/src/services/ebook/` exposed via Tauri IPC commands. Provide a drag-and-drop zone in Next.js that invokes native file picker or consumes dropped files.

### Implementation Flow
1. User drops an ebook file (`.epub`, `.pdf`, `.mobi`) into BookStudio.
2. Tauri IPC command `parse_ebook(file_path: String)` is called.
3. Rust engine determines format:
   - **EPUB:** Uses crate `epub` / `quick-xml` to read metadata, extract cover image into cache directory, parse `toc.ncx` / `nav.xhtml`, and extract chapter HTML files.
   - **PDF:** Uses crate `pdf-extract` or `lopdf` to extract text by pages/headings.
   - **MOBI:** Uses unpacker or converts to clean text structure.
4. Clean HTML tags (`<p>`, `<span>`, `<br>`) into structured plain text chapters with title, index, and raw word count.
5. Return `EbookMetadata` and `Vec<ChapterDTO>` to the frontend.

### Technical Approach

```rust
#[tauri::command]
pub async fn parse_ebook(file_path: String) -> Result<EbookData, String> {
    let path = std::path::Path::new(&file_path);
    match path.extension().and_then(|s| s.to_str()) {
        Some("epub") => services::ebook::epub_parser::parse_epub(&file_path),
        Some("pdf") => services::ebook::pdf_parser::parse_pdf(&file_path),
        Some(ext) => Err(format!("Unsupported file extension: {}", ext)),
        None => Err("File has no extension".into()),
    }
}
```
