# [FR-005] One-Click Sentence Audio Regeneration & Text Edit

## Labels
`MUS`, `enhancement`, `audio-editing`, `sentence-regeneration`

## User Story
As an editor, I want to edit text or adjust temperature and click "Regenerate" on any individual misread sentence so that I don't have to re-synthesize the entire 15-minute chapter when only one word was mispronounced.

## Proposed Solution

### Overview
Allow inline editing of sentence text (e.g. fixing typos, adding commas for better pacing, phonetic re-spelling for proper nouns). Provide a dedicated "Regenerate" action button per sentence that triggers an isolated TTS request and updates the waveform and project database.

### Implementation Flow
1. User clicks into a sentence row or text editor box.
2. User adjusts the text (e.g., changes "Phương Mộc" to "Phương Mộc," or adds quotation marks).
3. User can optionally tweak temperature for that single sentence (e.g., lower to `0.35` if tone was too high).
4. User clicks "Regenerate" (or presses `Ctrl+Enter`):
   - Sentence status changes to `generating`.
   - Rust invokes TTS endpoint with updated text and parameters.
   - Old audio file is backed up / overwritten in cache.
   - Waveform re-renders immediately with the newly synthesized audio.
   - Sentence duration and timestamps update in project state.

### Technical Approach

```typescript
async function handleRegenerateSentence(sentenceId: string, updatedText: string, customTemp?: number) {
  setSentenceStatus(sentenceId, 'generating');
  const result = await invoke<SentenceAudioResult>('regenerate_sentence', {
    sentenceId,
    text: updatedText,
    temperature: customTemp ?? defaultTemp,
  });
  updateSentenceAudio(sentenceId, result.audioPath, result.duration);
  setSentenceStatus(sentenceId, 'ready');
}
```
