# [FR-008] Multi-Voice & Character Dialogue Assignment

## Labels
`Future`, `enhancement`, `multi-speaker`, `audio-drama`

## User Story
As a storyteller, I want to assign distinct voices to narration vs character dialogue lines so that the audiobook sounds like a multi-cast drama.

## Proposed Solution

### Overview
Implement character tagger in the sentence segmentation pipeline. Allow user to define Character profiles (e.g., "Phương Mộc" -> Voice: Nam Trẻ / Hải Đăng, "Nữ chính" -> Voice: Thảo Nhi, "Dẫn truyện" -> Voice: Ngọc Lan) and tag individual dialogue sentences.

### Acceptance Criteria
- [ ] Character profile manager with custom voice presets per character.
- [ ] Auto-detection of dialogue quotes with suggested character assignments.
- [ ] Manual override per sentence in the UI table.
