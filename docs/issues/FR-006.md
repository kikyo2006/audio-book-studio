# [FR-006] Chapter Assembly & Multi-Format Audio Export

## Labels
`MUS`, `enhancement`, `audio-concatenation`, `export-engine`

## User Story
As a creator, I want to assemble all sentence audio files with natural inter-sentence pauses (configurable ms) and export the entire book/chapter into WAV (Master), MP3 (with ID3 tags & cover), and M4B (with chapter markers).

## Proposed Solution

### Overview
Implement high-performance audio concatenation in Rust using crate `hound` (for pristine lossless WAV joining) and FFmpeg sidecar (for encoding MP3 with ID3v2 tags and M4B with chapter cues).

### Implementation Flow
1. User clicks "Export" (single chapter or full book).
2. Configure export settings in `ExportModal.tsx`:
   - Inter-sentence pause duration (default: `350ms` silence).
   - Inter-paragraph pause duration (default: `750ms` silence).
   - Format: `WAV` (24-bit / 16-bit 48kHz), `MP3` (320kbps / 192kbps), or `M4B` (AAC Audiobook).
   - Metadata: Book title, Author, Narrator (e.g. `Thảo Nhi`), Year, Embedded Cover Art.
3. Rust backend reads sentence WAV files in order:
   - Generates pure silence PCM buffer for pauses.
   - Slices and writes PCM samples continuously into a master WAV file.
4. If format is MP3 or M4B:
   - Rust triggers FFmpeg sidecar with metadata arguments and embedded album art.
5. User selects target output path via native file dialog (`@tauri-apps/plugin-dialog`).

### Technical Approach

```rust
pub fn assemble_chapter_wav(
    sentence_paths: &[PathBuf],
    sentence_pause_ms: u32,
    output_path: &Path,
) -> Result<u64, String> {
    let spec = hound::WavSpec {
        channels: 1,
        sample_rate: 48000,
        bits_per_sample: 16,
        sample_format: hound::SampleFormat::Int,
    };
    let mut writer = hound::WavWriter::create(output_path, spec).map_err(|e| e.to_string())?;
    let pause_samples = (spec.sample_rate as f32 * (sentence_pause_ms as f32 / 1000.0)) as usize;

    for (i, path) in sentence_paths.iter().enumerate() {
        let mut reader = hound::WavReader::open(path).map_err(|e| e.to_string())?;
        for sample in reader.samples::<i16>() {
            writer.write_sample(sample.map_err(|e| e.to_string())?).map_err(|e| e.to_string())?;
        }
        if i + 1 < sentence_paths.len() {
            for _ in 0..pause_samples {
                writer.write_sample(0i16).map_err(|e| e.to_string())?;
            }
        }
    }
    writer.finalize().map_err(|e| e.to_string())?;
    Ok(output_path.metadata().unwrap().len())
}
```
