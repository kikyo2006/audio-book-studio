# [FR-003] TTS Engine Integration & Voice Preset Manager

## Labels
`MUS`, `enhancement`, `tts-engine`, `vieneu-tts`

## User Story
As a producer, I want to connect to a local TTS server ([[VieNeu-TTS]] via OpenAI Speech API) and choose voice presets (e.g. `Thảo Nhi`, `Ngọc Lan 18`, etc.) with speed and temperature sliders so that I have complete control over reading style.

## Proposed Solution

### Overview
Implement an asynchronous TTS worker queue in Rust that connects to the local [[VieNeu-TTS]] OpenAI-compatible server at `http://localhost:8880/v1/audio/speech`. Expose configuration in the frontend UI to select voices, customize temperature (`0.35` - `0.55`), and monitor queue status.

### Implementation Flow
1. UI has a Voice Selector dropdown (presets: `Thảo Nhi`, `Ngọc Lan 18`, etc.).
2. Health-check service checks if local server (`localhost:8880`) is active.
3. User triggers "Generate Chapter":
   - Sentences are dispatched to the Rust queue worker.
   - Queue calls `POST /v1/audio/speech` with payload:
     `{ model: "vieneu-v3-turbo", voice: selected_voice, input: sentence.clean_text, response_format: "wav" }`.
   - Resulting WAV bytes are streamed/saved to project cache: `cache/{project_id}/audio/{sentence_id}.wav`.
   - Rust emits `sentence-audio-ready` event with duration and file path.
4. UI updates row status from `generating` to `ready`.

### Technical Approach

```rust
#[derive(Serialize, Deserialize)]
pub struct TtsRequest {
    pub model: String,
    pub voice: String,
    pub input: String,
    pub response_format: String,
    pub speed: f32,
}

pub async fn synthesize_sentence(req: TtsRequest, output_path: &Path) -> Result<f32, String> {
    let client = reqwest::Client::new();
    let res = client.post("http://localhost:8880/v1/audio/speech")
        .json(&req)
        .send()
        .await
        .map_err(|e| e.to_string())?;
    let bytes = res.bytes().await.map_err(|e| e.to_string())?;
    tokio::fs::write(output_path, &bytes).await.map_err(|e| e.to_string())?;
    // Calculate and return duration in seconds
    get_wav_duration(output_path)
}
```
