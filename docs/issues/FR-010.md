# [FR-010] Embedded Offline Piper/Sherpa-ONNX Engine

## Labels
`Future`, `enhancement`, `offline-engine`, `sherpa-onnx`

## User Story
As an offline user, I want the option to synthesize audio directly inside the desktop app using lightweight ONNX models (e.g. `thao-nhi-tts-onnx`) without needing an external Python server.

## Proposed Solution

### Overview
Embed `sherpa-rs` or `ort` (ONNX Runtime Rust bindings) directly in the Tauri backend binary to execute Piper VITS models (`vi_VN-thaonhi.onnx` ~60MB) locally on CPU with zero external dependencies.

### Acceptance Criteria
- [ ] Bundled lightweight Piper ONNX runtime in Rust.
- [ ] Toggle between "VieNeu-TTS Studio 48kHz (Server)" and "Piper Offline 22kHz (Embedded)".
