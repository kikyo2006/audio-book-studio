# [FR-002] Smart Sentence Segmentation & Text Normalization

## Labels
`MUS`, `enhancement`, `nlp-tokenizer`, `text-processing`

## User Story
As an editor, I want book chapters to be automatically split into clean, granular sentences with smart punctuation handling (dialogue dashes `—`, quotes `""`, ellipses `...`) so that TTS reading sounds natural without sentence clipping.

## Proposed Solution

### Overview
Implement a specialized Vietnamese & English sentence tokenizer. It handles abbreviations (e.g. `TP.HCM`, `Mr.`, `Dr.`, `GS.`, `TS.`), numbers with decimals (`3.14`, `1.5m`), dialogue prefixes (`—`, `-`, `"..."`), and long run-on sentences.

### Implementation Flow
1. Receive chapter plain text.
2. Run normalization:
   - Normalize quotes (`“`, `”` $\rightarrow$ `"`).
   - Normalize dashes (`–`, `—` $\rightarrow$ `— `).
   - Collapse excessive whitespace and linebreaks.
3. Apply sentence boundary detection:
   - Split on terminal punctuation followed by space or quote (`[.?!]+(?=\s|$)`).
   - Guard against common abbreviations and numeric patterns.
   - For sentences exceeding max character threshold (e.g. > 150 characters), gently split at commas `,` or semicolons `;` to prevent TTS attention degradation.
4. Output indexed sentence entities:
   `{ id: string, chapter_id: string, index: number, text: string, status: "pending" }`.
